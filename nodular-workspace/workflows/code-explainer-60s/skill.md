# Code-drawn explainer skill

This file is for the planner only. Do not paste it into a scene brief.

## Picture
Draw every frame in code. No stock footage and no filmed plates. Light the scene like a soft sun through haze, with a sky that has color. Empty gray plastic on a flat background is a failed look.

## Script
About 60 seconds, spoken, one idea per sentence. The sentence names the thing the picture shows. Offer three hooks and leave the choice to the person. Hooks are specific, not a promise of what the viewer will learn.

## Brief
One scene per sentence. For each scene write: the sentence, the word that names the visual, what moves on that word, and which catalog ids to look up. The brief is the only context the builders get.

## Motion
The camera is shared across the whole film. A phone has to be able to follow it. Elements arrive or change on the word that names them. Do not hold a frame still while the voice keeps talking. Do not flash brightness or color between neighboring frames. Type stays large enough to read on a phone.

## Tiers
Express: one pass, canvas, SVG, and CSS, then a single review.
Standard: the same drawing tools, one scene at a time, reviewed before the next scene.
Studio: the same timing rules, with procedural 3D drawn on a canvas in the page. Catalog rows are placeholders, not model files.

## Hand-off
Return the brief only. Do not return this skill, the check thresholds, or HTML.
